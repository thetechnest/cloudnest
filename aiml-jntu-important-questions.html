Important 5-Marks Questions (JNTU Ananthapur)

1️⃣ What is a Cloud Machine Learning service?

Cloud ML services provide managed platforms to build, train, deploy, and monitor machine learning models without managing hardware or infrastructure. They help in faster development, scalability, and reliability.
Impact: Cloud ML converts ideas into real-world AI systems.

2️⃣ Explain AWS SageMaker.

AWS SageMaker is a fully managed service that supports data preparation, model training, hyperparameter tuning, deployment, and monitoring from a single platform.
Impact: SageMaker simplifies the complete ML lifecycle.

3️⃣ What is Azure Machine Learning?

Azure ML is a cloud service used to build, train, and deploy ML models with strong enterprise integration and security features.
Impact: Preferred in enterprise and corporate environments.

4️⃣ What is GCP Vertex AI?

Vertex AI is Google Cloud’s unified ML platform that supports AutoML, custom training, pipelines, and deployment in a single environment.
Impact: Simplifies ML workflows using a single platform.

5️⃣ Explain training and deployment of ML models on cloud.

Training uses scalable cloud compute resources to build models. Deployment makes the trained model available as an API or batch job for real-time or offline predictions.
Impact: Deployment brings business value to ML.

6️⃣ What is AutoML?

AutoML automates algorithm selection, feature engineering, and hyperparameter tuning with minimal coding.
Impact: Enables quick model development for beginners.

7️⃣ What is Custom ML?

Custom ML allows developers to design their own algorithms, model architectures, and training logic for better control and performance.
Impact: Used in real production ML systems.

8️⃣ Why are GPUs and TPUs used in ML?

GPUs and TPUs perform parallel processing which reduces training time for deep learning models significantly.
Impact: Makes large-scale AI training practical.

9️⃣ What is experiment tracking and model evaluation?

Experiment tracking records parameters and results of different models. Model evaluation measures performance using metrics before deployment.
Impact: Helps select the best performing model.

🔟 Why integrate notebooks with cloud storage?

Notebook integration with cloud storage allows scalable data access, persistent storage, and easy collaboration among teams.
Impact: Turns experiments into team-based ML projects.
