Case Study Questions – Cloud ML with Algorithms & MLOps

Case Study 1: Predictive Maintenance – Automobile Industry

Problem: Predict engine failure using continuous sensor data.

ML Algorithm: LSTM (Long Short-Term Memory) for time-series sensor data.

Why this Algorithm?
Engine data is sequential and temporal. LSTM captures long-term dependencies and trends better than traditional regression.
How it Works?
Sliding time windows → Feature sequences → LSTM training → Failure probability output.

AWS Architecture:
Sensors → IoT Core → Kinesis → S3 → SageMaker (GPU Training) → Auto-scaling Endpoint → Alerts

Elasticity & Availability:
SageMaker endpoint auto-scales based on traffic and runs across multiple AZs.
CI/CD (MLOps):
CodeCommit → CodeBuild (train) → SageMaker Pipeline → Model Registry → Blue/Green deployment.
GCP Line: Pub/Sub → GCS → Vertex AI LSTM pipeline with autoscaling.

Case Study 2: Fraud Detection – Banking

ML Algorithm: Random Forest / XGBoost

Why? Handles imbalanced data, non-linear patterns, and feature interactions well.

AWS Architecture:
API Gateway → Lambda → SageMaker Endpoint → DynamoDB

Elasticity: Lambda + endpoint auto-scale for transaction spikes.
CI/CD: Git commit triggers retraining when fraud patterns drift.
GCP Line: Cloud Functions + Vertex AI endpoint.

Case Study 3: Customer Churn Prediction – Telecom

ML Algorithm: Logistic Regression / Gradient Boosting

Why? Interpretable model helps business teams understand churn drivers.

AWS Architecture:
CRM → S3 → SageMaker Training → Batch Transform → BI Tools

Elasticity: Batch jobs scale compute only during execution.
GCP Line: BigQuery ML / Vertex AI batch prediction.

Case Study 4: Image-Based Defect Detection

ML Algorithm: CNN (ResNet / EfficientNet)

Why? CNNs extract spatial features from images effectively.

AWS Architecture:
Cameras → S3 → SageMaker GPU Training → Multi-AZ Endpoint → QC System

Availability: Multi-AZ deployment ensures zero downtime.
GCP Line: Vertex AI Vision with GPU/TPU.

Case Study 5: Vehicle Health Dashboard

ML Algorithm: Random Forest + Threshold Rules

Why? Combines ML prediction with rule-based alerts for reliability.

AWS Architecture:
Kinesis → S3 → SageMaker → API Gateway → Dashboard

CI/CD: Dashboard + ML model version updated independently.
GCP Line: Pub/Sub + Vertex AI + Looker.
