Case Study Questions – Cloud ML (AWS Architecture Focus)

Case Study 1: Predictive Maintenance – Automobile Industry

Problem: Predict engine failure using real-time vehicle sensor data.

AWS Architecture:
Sensors → AWS IoT Core → Kinesis Data Streams → S3 (Data Lake) → SageMaker Training → SageMaker Endpoint → Alerts/Dashboard

Design: Streaming ingestion, batch + real-time predictions, scalable ML inference.
Implementation (AWS): IoT Core for ingestion, S3 for storage, SageMaker for training & deployment, CloudWatch for monitoring.
GCP Line: Same workflow using IoT Core, Pub/Sub, GCS, and Vertex AI.

Case Study 2: Real-Time Fraud Detection – Banking

Problem: Detect fraudulent transactions in milliseconds.

AWS Architecture:
Transaction Apps → API Gateway → Lambda → SageMaker Endpoint → DynamoDB → Alerts

Design: Low-latency serverless inference with autoscaling.
Implementation (AWS): Lambda invokes SageMaker real-time endpoint, DynamoDB stores prediction outcomes.
GCP Line: Use Cloud Functions + Vertex AI Endpoint + Firestore.

Case Study 3: Customer Churn Prediction – Telecom

Problem: Predict customers likely to leave the service.

AWS Architecture:
CRM Data → S3 → SageMaker Training → Batch Transform → S3 → BI Dashboard

Design: Batch prediction with scheduled retraining.
Implementation (AWS): SageMaker batch transform jobs and experiment tracking.
GCP Line: BigQuery + Vertex AI batch predictions.

Case Study 4: Image-Based Defect Detection – Manufacturing

Problem: Detect defective products using images.

AWS Architecture:
Cameras → S3 → SageMaker (GPU Training) → Endpoint → Quality Control System

Design: Deep learning with GPU acceleration.
Implementation (AWS): CNN models trained using GPU instances in SageMaker.
GCP Line: Vertex AI with GPU/TPU-backed training.

Case Study 5: Vehicle Health Dashboard – Fleet Management

Problem: Monitor vehicle health and predict failures.

AWS Architecture:
Telemetry → Kinesis → S3 → SageMaker → API Gateway → Dashboard

Design: Unified analytics + ML inference.
Implementation (AWS): Notebook-based analysis, model deployment, visualization layer.
GCP Line: Pub/Sub + Vertex AI + Looker dashboards.
