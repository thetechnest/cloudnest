Cloud Machine Learning – Important FAQs (5 Marks Each)

1️⃣ What are Cloud ML services and why are they required?
Cloud ML services provide managed platforms to build, train, deploy, and monitor machine learning models without managing infrastructure. They support scalability, automation, security, and MLOps required for enterprise systems.
Real-time: Predictive maintenance using AWS SageMaker
Exam Line: Cloud ML services enable scalable and production-ready machine learning.
2️⃣ How does AWS SageMaker support the ML lifecycle?
SageMaker supports data preparation, training, tuning, deployment, monitoring, and retraining through Studio, Pipelines, Model Registry, and Endpoints.
Real-time: Vehicle health prediction as real-time endpoint
Exam Line: SageMaker provides end-to-end managed ML lifecycle.
3️⃣ Explain Azure Machine Learning and its use cases.
Azure ML is a cloud service for building and managing ML models with strong enterprise integration, security, and DevOps support.
Real-time: Engine overheating alerts integrated with dashboards
Exam Line: Azure ML supports enterprise-grade machine learning.
4️⃣ What is GCP Vertex AI?
Vertex AI is a unified ML platform combining AutoML, custom training, pipelines, and deployment with strong data integration.
Real-time: Brake failure prediction
Exam Line: Vertex AI simplifies ML lifecycle using unified services.
5️⃣ Explain training and deploying models on cloud.
Cloud training uses scalable compute while deployment exposes models as APIs or batch jobs, enabling real-time inference and monitoring.
Real-time: Fleet-wide failure prediction APIs
Exam Line: Cloud deployment makes ML scalable and reliable.
6️⃣ What is AutoML and where is it useful?
AutoML automates feature selection, algorithm choice, and tuning, enabling rapid model development with minimal coding.
Real-time: Baseline failure model using AutoML
Exam Line: AutoML accelerates ML model development.
7️⃣ What is Custom ML and why is it important?
Custom ML gives full control over algorithms and architectures, enabling optimized, domain-specific models.
Real-time: LSTM-based vehicle sensor analysis
Exam Line: Custom ML enables high-performance production models.
8️⃣ Why are GPUs and TPUs used in model training?
GPUs and TPUs perform massive parallel computation, drastically reducing training time for deep learning models.
Real-time: Deep learning-based fault detection
Exam Line: Accelerators speed up deep learning training.
9️⃣ What is experiment tracking and model evaluation?
Experiment tracking records parameters and metrics, while evaluation ensures models perform well on unseen data.
Real-time: Selecting best maintenance model
Exam Line: Tracking ensures reproducibility and reliability.
🔟 How do notebooks integrate with cloud storage?
Notebooks connect to cloud storage to read large datasets and store models, logs, and outputs for collaboration.
Real-time: Jupyter with cloud buckets
Exam Line: Notebook integration enables scalable ML workflows.
