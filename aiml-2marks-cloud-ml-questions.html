Cloud ML • 2 Marks Revision

Important 2 Marks Questions – Cloud Machine Learning

1️⃣ What is a cloud ML platform?

A cloud ML platform is a managed service that allows building, training, deploying, and monitoring ML models at scale.
Tip to remember: Cloud ML = ML + Scalability + Automation

2️⃣ What is the role of SageMaker in ML?

SageMaker provides end-to-end ML lifecycle support including training, deployment, monitoring, and retraining.
Tip to remember: SageMaker = Full MLOps on AWS

3️⃣ Why is model deployment important?

Deployment makes a trained model available for real-time or batch predictions through APIs.
Tip to remember: No deployment = No business value

4️⃣ What is AutoML?

AutoML automates algorithm selection, feature engineering, and hyperparameter tuning.
Tip to remember: AutoML = Speed over control

5️⃣ What is Custom ML?

Custom ML allows full control over data preprocessing, algorithms, and model architecture.
Tip to remember: Custom ML = Control over performance

6️⃣ Why are GPUs used in ML training?

GPUs perform parallel computation which significantly reduces deep learning training time.
Tip to remember: GPU = Parallel processing

7️⃣ What is experiment tracking?

Experiment tracking records model parameters, datasets, and metrics to compare and reproduce results.
Tip to remember: No tracking = No reproducibility

8️⃣ What is model evaluation?

Model evaluation measures how well a model performs on unseen data using metrics.
Tip to remember: Accuracy alone is not enough

9️⃣ Why integrate notebooks with cloud storage?

Integration enables scalable data access, persistence, and collaboration.
Tip to remember: Notebook + Cloud = Team ML

🔟 What is MLOps?

MLOps is the practice of automating and managing the ML lifecycle in production.
Tip to remember: MLOps = DevOps for ML
